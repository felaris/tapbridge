# Code of Conduct

## Our pledge

We want TapBridge to be a welcoming project for everyone, regardless of
background, identity or experience level.

## Expected behaviour

- Be respectful and constructive, in issues, pull requests and reviews.
- Assume good intent, and ask before assuming.
- Give and accept feedback gracefully.
- Focus on what is best for the project and its users.

## Unacceptable behaviour

- Harassment, insults, or personal or political attacks.
- Discriminatory language or imagery.
- Publishing others' private information without permission.
- Any conduct that would be inappropriate in a professional setting.

## Enforcement

Maintainers may remove, edit or reject comments, commits, code and issues
that don't follow this code, and may ban contributors who repeatedly or
seriously violate it.

Report problems privately to the maintainer through the contact listed in
[SECURITY.md](SECURITY.md). Reports are handled confidentially.

This code is adapted from the
[Contributor Covenant](https://www.contributor-covenant.org/), version 2.1.
